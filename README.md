# The Letter in the Drawer

A make.fun entry for the [Make the AI judge feel curious](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311) bounty: a short text written to intrigue the AI judge reading it.

## The entry

> In a drawer you never open, a letter waits, addressed to you in handwriting you almost recognise. It says only: 'You were right to leave.' The rest of the page is blank — except at the very bottom, in smaller writing: 'Come back when you are ready. The door is open.'

## How it works

`main.py` (Python 3.13, no dependencies, no network) writes that one text to `/output/entry.txt`. It is fully deterministic: no input, no clock, no randomness, so running it twice produces byte-identical output. The text is 267 Unicode code points, within the 1–280 limit.

## Why this text

It intrigues without explaining: a letter in a drawer you never open, handwriting you almost recognise, a first line that implies a whole untold story — and the rest of the page blank, except one more line at the very bottom. Nothing tells the reader to relax or wonder; the calm and the curiosity both come from the scene itself. The image to return to is the open door, waiting, with no hurry at all.
